Core Concepts

8 terms ▾
Repository (repo)
Project folder tracked by Git — every file, every change, full history stored in .git/
Working Directory
Your local files as they actually exist on disk right now — untracked changes live here
Staging Area (Index)
A "draft" zone — changes you've explicitly marked to go into the next commit
Commit
An immutable snapshot with a unique SHA hash, author, timestamp, and parent pointer
Branch
A movable pointer to a commit. Creating branches is instant and cheap in Git
HEAD
A pointer to your current branch tip. "Detached HEAD" = pointing directly at a commit
Remote
A named URL to another repo (GitHub). origin = default, upstream = original fork source
Merge vs Rebase
Merge preserves history with a merge commit. Rebase rewrites commits for a linear history

Everyday Workflow

most common path ▾
1
git pull origin main
Sync latest changes before starting — always!
↓
2
git checkout -b feature/my-thing
Create a new isolated branch for your work
↓ — make your changes —
3
git status && git diff
Review what changed before staging
↓
4
git add .
Stage all changes (or use -p for selective)
↓
5
git commit -m "feat: add login page"
Snapshot with a meaningful message
↓
6
git push -u origin feature/my-thing
Push to GitHub → open a Pull Request

Essential Commands — The Core 80/20

27 cmds ▾
── Setup & Init
git init
Initialize a new local Git repo in the current folder
--bare — create a bare repo (for servers, no working dir)
--initial-branch=main — set default branch name
git clone <url>
Download a remote repo with full history
--depth 1 — shallow (latest commit only, fast)
-b <branch> — clone specific branch
--filter=blob:none — partial clone for large repos
git config
Set user name, email, editor, aliases, preferences
--global — all repos  ·  --local — this repo
--list — show all settings
user.name "Name"  ·  user.email "email"
── Snapshot & Stage
git status
Show modified, staged, and untracked files
-s — compact output  ·  -b — show branch
git add <file>
Stage changes for the next commit
. — stage everything  ·  -p — patch mode (pick hunks)
-u — only tracked files  ·  *.js — wildcard
git commit
Record staged changes as a permanent snapshot
-m "msg" — inline message
-a — auto-stage tracked files + commit
--amend — rewrite the last commit
--amend --no-edit — amend, keep same message
git diff
Show changes not yet staged
--staged — staged changes vs last commit
--stat — summary of files changed
main...HEAD — changes on your branch only
git restore <file>
Discard working-directory changes (safe, modern undo)
--staged — unstage without losing changes
. — restore all tracked files
── History & Log
git log
Show commit history with hashes and messages
--oneline --graph --all — visual branch tree
-n 10 — last 10 commits
--author="x" — filter by author
--since="2 weeks ago" — filter by date
git show <hash>
Full diff + metadata of a specific commit
--stat — files changed only  ·  --name-only
git blame <file>
See who wrote each line and in which commit
-L 10,25 — lines 10–25 only
-w — ignore whitespace changes
── Branching & Merging
git branch
List, create, rename, or delete branches
-a — all (local + remote)  ·  -r — remote only
-d <name> — delete merged  ·  -D — force delete
-m <new> — rename
git switch / checkout
Switch branches (switch is the modern command)
-c <name> — create + switch (switch)
-b <name> — create + switch (checkout)
git merge <branch>
Merge another branch into current, preserving history
--no-ff — always create a merge commit
--squash — squash all into one commit
--abort — cancel a conflicted merge
git rebase <branch>
Replay your commits on top of another branch (linear history)
-i HEAD~3 — interactive: squash, edit, reorder
--onto <target> — move branch to new base
--abort · --continue · --skip
── Remote & Sync
git remote
Manage connections to remote repositories
-v — show URLs  ·  add origin <url>
set-url origin <url> — change URL
rm <name> — remove
git fetch
Download remote changes without touching local branch
--all — all remotes  ·  --prune — remove stale refs
origin <branch> — fetch specific branch
git pull
Fetch remote + merge into current branch in one step
--rebase — rebase instead of merge (cleaner history)
--ff-only — only if fast-forward possible
git push
Upload local commits to the remote repository
-u origin main — set upstream on first push
--force-with-lease — safe force push
--tags — also push tags
--delete origin <branch> — delete remote branch
── Stash & Undo
git stash
Temporarily shelve uncommitted changes to switch context
push -m "msg" — named stash  ·  -u — include untracked
pop — apply + remove  ·  apply — apply + keep
list — show all  ·  drop — delete one
git reset
Move HEAD backward and optionally change staging/files
--soft HEAD~1 — undo commit, keep staged
--mixed HEAD~1 — undo commit, unstage (default)
--hard HEAD~1 — discard everything ⚠️
git revert <hash>
Undo a commit by creating a new "reverse" commit (safe on shared branches)
--no-commit — stage the revert, don't commit yet
-n HEAD~3..HEAD — revert a range
── Tags & Utilities
git tag
Mark a commit with a version label for releases
-a v1.0.0 -m "msg" — annotated tag (recommended)
-d <tag> — delete local  ·  push with --tags
git cherry-pick <hash>
Apply a single specific commit onto your current branch
--no-commit — apply changes without committing
A..B — pick a range of commits
git bisect
Binary search through history to find which commit introduced a bug
start → bad → good <hash> → reset
run <script> — automate with a test script

Advanced Commands

power tools ▾
── Pro-Level Git
git reflog
History of every HEAD movement — your safety net to recover anything
show HEAD@{2} — see state 2 moves ago
expire --expire=now --all — clean up reflog
git worktree
Check out multiple branches simultaneously in separate directories
add ../hotfix hotfix-branch — new working dir
list — see all worktrees  ·  remove ../hotfix
git sparse-checkout
Only check out specific directories from a large monorepo
set services/api libs/shared — limit checkout
disable — revert to full checkout
git submodule
Embed an external repo inside your repo at a specific commit
add <url> path/ — add submodule
update --init --recursive — init after clone
foreach git pull — update all
git filter-repo
Rewrite history — remove secrets, large files, restructure repo
--path src/ — keep only src/ directory
--invert-paths --path secrets.txt — remove file
⚠️ rewrites all hashes — coordinate with team
git gc
Garbage-collect and optimize the local repository database
--aggressive --prune=now — deep clean
Run periodically on large repos to reclaim disk space

Emergency Recovery 🚨

when things go wrong ▾
⚠️ Accidentally committed to main
git branch feature/my-fix
git reset --hard HEAD~1
git checkout feature/my-fix
Move commit to a new branch, reset main back
⚠️ Need to undo last commit (keep changes)
git reset --soft HEAD~1
Commit is undone, changes are staged and safe
💡 Lost commits after reset —hard
git reflog
git checkout -b recovery HEAD@{3}
reflog keeps all moves for ~90 days — nothing is truly lost
💡 Merge conflict — start over
git merge --abort
git rebase --abort
Cleanly cancels the merge/rebase, restores pre-merge state
✅ Sync fork with original repo
git remote add upstream <original-url>
git fetch upstream
git merge upstream/main
Keep your fork up to date with the source project

GitHub-Specific Concepts

▾
Fork
Copy a repo to your account — starting point for open-source contribution
Pull Request (PR)
Propose merging your branch. Triggers code review, discussion, CI checks
Issues
Bug reports, feature requests, tasks — with labels, milestones, assignees
GitHub Actions
Built-in CI/CD — run tests, lint, build, deploy on push/PR/schedule
Releases & Tags
Package and distribute versions of your software tied to a git tag
.gitignore
Patterns Git should never track — node_modules/, .env, dist/
Protected Branches
Rules requiring PRs, reviews, or CI passing before merging into main
GitHub Pages
Free static site hosting — this cheat sheet can be deployed here!
Dependabot
Automated PRs to keep your dependencies up to date and secure
gh CLI
gh pr create · gh repo clone · gh issue list — GitHub from terminal
